# Android Capacitor Project (android)

This directory contains the native Android Studio project generated by Capacitor.

## Developer Commands

Every time you change the web code in the project root:
1. Rebuild/copy static files to the web output directory:
   ```bash
   npm run build:web
   ```
2. Sync the assets to the Android native folder:
   ```bash
   npx cap sync
   ```
3. Open in Android Studio to build, run, or publish:
   ```bash
   npx cap open android
   ```

## Configuration & Limitations

> [!WARNING]
> Google blocks standard webview logins (OAuth) when it detects custom webview layouts or automation.
> - To bypass this, configure a custom User-Agent in `capacitor.config.ts` under the `overrideUserAgent` key (e.g., standard Safari/Chrome browser UA).
> - Enable cookies and script execution on your WebView container inside `MainActivity.java`.
